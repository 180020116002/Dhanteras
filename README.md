# 🪔 Shubh Dhanteras — Interactive Festive Experience

An interactive Dhanteras celebration web app featuring falling gold coins, interactive collection physics, sacred sound effects, and blessings of Maa Lakshmi and Lord Kuber.

✨ **Live Preview**: [https://180020116002.github.io/Dhanteras/](https://180020116002.github.io/Dhanteras/)

---

## 🌟 Highlights & Features

- 🪙 **Interactive Coin Catcher**: Drag or touch across the screen to gather falling gold coins into the sacred Kalash.
- 🪔 **Lakshmi Ji Blessings**: Displays the total prosperity gathered with personalized festive wishes.
- 🔔 **Synthesized Ambient Audio**: Dynamic temple bell tolls and festive sound effects powered by the Web Audio API (no heavy audio files needed).
- 📲 **Viral WhatsApp Sharing**: One-tap WhatsApp & Link Sharing with pre-formatted festive messages so users can send prosperity wishes to their family & friends.
- 🖼️ **Social Preview Card (Open Graph)**: Optimized 1200x630 preview image (`og-image.png`) that renders rich preview cards on WhatsApp, Twitter/X, iMessage, Facebook, Telegram, and LinkedIn.
- 💌 **Personalized Greetings**: Append `#YourName` or `#FriendName` to the URL (e.g. `https://180020116002.github.io/Dhanteras/#Aarohi`) to display a personalized wish!

## 🚀 Deployment

### GitHub Pages (Recommended)
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://180020116002.github.io/Dhanteras/`.

### Netlify
1. Connect this repository to [Netlify](https://www.netlify.com/).
2. Build settings are already configured in `netlify.toml`.
3. Deploy directly!
